# وفّر فلوسك | Waffir Floussek — واجهة أولية

## المحتويات
- `src/App.tsx`: الصفحة الرئيسية التفاعلية.
- `src/App.css`: التصميم المتجاوب والألوان.
- `package.json`: إعدادات مشروع React + Vite.
- `index.html`: نقطة الدخول.

## التشغيل محلياً
1. أنشئ مشروع React + TypeScript باستخدام Vite.
2. انسخ `src/App.tsx` و`src/App.css` إلى مجلد `src`.
3. تأكد أن `src/main.tsx` يستورد `App` وملف CSS من داخل `App.tsx`.
4. شغّل `npm install` ثم `npm run dev`.

## رفعه إلى Google AI Studio
يمكنك رفع ملفات `App.tsx` و`App.css` أو فك ضغط المشروع ورفع الملفات إلى مساحة العمل التي تستعملها في AI Studio. إذا كان مشروعك الحالي فيه ملفات جاهزة، لا تستبدلها كلها دون نسخة احتياطية؛ اطلب من AI Studio دمج الصفحة مع بنية المشروع الحالية.

## حدود النسخة الحالية — مهم
هذه **واجهة تجريبية فقط**:
- لا توجد قاعدة بيانات أو حسابات فعلية.
- لا يتم تخزين كلمات المرور ولا إرسالها إلى خادم.
- الرصيد والأرقام والأنشطة المعروضة بيانات شكلية.
- أزرار الإيداع والسحب تعرض نماذج تجريبية فقط ولا تحوّل الأموال.
- رابط الإحالة تجريبي ولا ينشئ إحالات حقيقية.

قبل إطلاق منصة تتعامل مع أموال حقيقية، يجب بناء خادم موثوق وقاعدة بيانات، وتطبيق صلاحيات وأمن مناسبين، وربط مزود أداء مرخّص بعد التحقق من المتطلبات القانونية والتنظيمية في البلد المستهدف.
